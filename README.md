# Lost in the Garden

A small cozy browser game about wandering through a gentle garden and collecting flowers with sweet notes waiting inside.

## How to Play

- Move with the arrow keys, `WASD`, or the on-screen touch controls on mobile
- Explore the garden and collect all 4 flowers
- Read each note and unlock the final ending message
- Use `Restart` to begin again right away

## Run Locally

This project is a simple `HTML` / `CSS` / `JavaScript` browser game.

Open `index.html` in a browser to play locally.
